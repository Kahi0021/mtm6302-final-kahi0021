# Café Collector

Café Collector is a web application that helps Ottawa coffee lovers discover independent cafés. Users can filter cafés by coffee type, compare prices and popularity, like cafés, save their favourites, and keep notes about their visits.

## Project Information

- **Developer:** Maha Kahil
- **Client:** Cat Legault
- **Course:** MTM6302 – Final Project

## Main Features

- Browse a list of 11 independent Ottawa cafés.
- Filter cafés by five coffee types:
  - Latte
  - Cappuccino
  - Macchiato
  - Americano
  - Espresso
- Filter cafés by price and popularity.
- Like cafés.
- Save and unsave favourite cafés.
- Add and remove personal notes.
- View saved cafés.
- Clear the Saved list without removing Likes or notes.
